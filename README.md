# Ben Coxford — professional website

A dependency-free, static portfolio and notebook. Open `index.html` in a browser to preview it, or publish the files with any static hosting provider (including GitHub Pages).

Photos on the running page load lazily. Use the gallery controls to browse its photos. With JavaScript disabled, all photos remain visible.

In the Rwanda article, select a gallery photo to open the viewer and browse photos with the buttons or arrow keys. Videos remain playable in the gallery grid.
